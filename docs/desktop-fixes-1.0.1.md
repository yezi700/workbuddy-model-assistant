# 桌面版 1.0.1 修复说明

- 修复 Electron 不支持 `window.prompt` 导致登录和账号改名无法操作；统一采用可取消的应用内弹窗。
- 服务重启后自动恢复失效的控制台会话。只重试只读请求；写操作明确提示未执行，不重复提交。
- “更多模型”默认只显示已登录渠道。可勾选“显示未登录渠道”查看内置目录，这些行不能选择或发起检查。
- 退出、删除或禁用账号后同步刷新模型列表；后端也拒绝选择未登录或已停用渠道。
- 登录状态检查优先于模型目录缓存，退出后不会继续返回旧的登录目录。
- 价格未知时展示原因；内置清单不含可靠价格，不能视为免费，不复制其他渠道的价格。
- 国际 CodeBuddy / WorkBuddy 账号提示明确说明：同一国际账号共用 Buddy AI 权益和 Credits，余额不能相加，切换产品不能补充额度。两个渠道的登录授权、模型可用性及免费活动仍分别确认。
- 额度查询绑定本次选定账号，防止并发查询多个账号时使用错误的身份头。

验证：404 项测试通过；开发版和 Windows 打包版验证包括输入弹窗、登录取消、服务启停/重启、失效会话恢复、不重放写操作、未登录模型展示，以及退出清理。

2026-10-12 对用户当前国际账号进行了只读核验：CodeBuddy 和 WorkBuddy 的官方计费入口返回完全相同的额度资源记录。这确认了该账号共享同一 Credits 额度池。核验没有发送模型请求，没有重新登录已退出的 CodeBuddy 渠道；凭据和原始账单记录不包含在发布物中。
