## 免费额度与账号切换

本机日志中的上游错误为 HTTP 429 / code 6004：“使用量超出频率限制”，并附有重置时间和可切换其他模型的提示。之前只冷却 30 秒，而跨渠道回退不接受普通 429，因此反复请求同一个国内账号。

新版本识别这种模型日额度限制，按“账号＋模型”记录暂停到上游重置时间。普通短期限流继续使用 Retry-After；整个账号积分不足仍使用账号耗尽规则。账号页显示受限模型和重置时间，其他模型仍可使用。

执行顺序是：同渠道尝试其他可用账号，再尝试使用规则明确允许的备用渠道。后续请求跳过尚未重置的受限模型。到期自动恢复；必要时可用账号的「重置状态」手动清除限制。

切换只发生在尚未输出有效回复时；已经输出正文或工具调用后不会重放请求，以免重复执行。每次尝试账号数量仍受界面中的设置限制。

本机现有 Step 规则允许国内渠道切到国际渠道。本次保留该规则。严格免费模式只允许接口明确确认免费的备用模型；参考目录或未知价格不会被当作免费。若使用“允许指定备用渠道”且未勾选免费检查，实际费用仍取决于该账号的上游活动。

## 验证

- 440 项后端自动测试通过。
- 12 项真实 Electron 页面操作测试通过，覆盖刷新、切页、取消授权、重复点击、参数及网络错误。开发者可运行 `npm run test:ui` 重测。
- 桌面启停、托盘、会话恢复及参数弹窗沿用 18 项检查。
- 模拟国内账号受限、国际账号 B 受限、国际账号 C 成功：Chat Completions、Responses、Anthropic 均成功；后续两次请求直接使用 C，不再请求 A/B。
- 模拟备用渠道收费：严格免费模式停止返回错误，没有向收费渠道发送请求。
