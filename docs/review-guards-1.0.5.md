# 1.0.5 审查问题修复

修复 1.0.4 审查中复现的四项问题，保留国内版WorkBuddy、国际版WorkBuddy AI 两个渠道和现有价格获取功能。

- 免费或定时规则损坏时，暂停对应模型，控制台显示原因和「修正规则」。不会丢弃限制后继续走普通收费路由。保护覆盖三种兼容协议、别名、指定渠道和模型检查。其他配置保存及重启后仍保留保护；无法识别受影响模型时拒绝启动。
- 余额缓存按账号、渠道、数据目录及组织隔离。显示账号和查询余额绑定同一个账号，刷新账号池后更新对应缓存，避免切换账号后显示前一个账号的余额。
- 原子写入失败时保留旧文件、清理临时文件并返回错误，取消直接覆盖旧文件的回退。桌面端配置初始化、迁移、导入和端口修改使用同一写入工具。导入多个文件仍依赖备份恢复，不是多文件事务。
- 普通 HTTP 429 限流与真实额度不足分开处理。普通限流按 Retry-After 暂停账号（1 秒至 15 分钟，无提示时 30 秒），尝试其他可用账号；确认额度不足仍标记耗尽。修复流式响应包装遗漏 Retry-After 的问题。

验证：428 项自动测试全部通过；打包后的桌面应用 17 项检查全部通过。新增测试用本地模拟上游复现错误规则、跨账号余额、限流恢复、真实额度不足和文件写入失败，不消耗真实模型额度。

本机安装验证：版本 1.0.5，配置及账号凭证与升级前备份一致；国际版读取到 16 条官方价格，过期零价活动不被当作免费。
