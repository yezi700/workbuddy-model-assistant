# 国际版价格读取（1.0.3）

根因：旧程序使用 `/console/enterprises/personal/models`，国际版该路径返回无效响应；可用接口为 `/v2/enterprises/personal/models`。现在国际版优先使用 v2 接口，兼容旧路径，总超时仍受同一个预算限制。

本机账号的实时接口返回 18 个官方模型，其中 16 项可以确认倍率。例如 GPT-5.4 为 x1.65、GPT-5.6 Sol 为 x3.47、Gemini 3.5 Flash 为 x0.99。具体值随上游变化，界面会显示实际读取时间。

界面新增“刷新目录与价格”，只查询模型元数据，不发送聊天请求。价格按官方 Credits 倍率展示，不能解释为固定金额或每次请求扣除的 Credits 数量。

成功获取的目录保存到用户数据目录中的 `model-catalog-cache.json`。缓存按站点、账号身份、组织和接口地址隔离；不保存凭据。服务重启或接口失败时可恢复旧价格，显示缓存标记和原始更新时间。

过期促销、未生效促销，以及失效缓存中的零倍率不会作为当前免费依据。界面保留上游原始零倍率并说明原因，不将其直接显示为当前免费。

参考模型仍然保留。未出现在当前账号官方目录中的模型不会复制其他站点的价格，显示费用未确认。目录存在不等于已通过聊天权限验证。

验证：410 项测试通过，包括 v2 优先、旧接口兼容、总超时、缓存账号隔离、模拟进程重启后的磁盘缓存恢复及促销边界。Windows 打包版通过 17 项桌面检查。未进行真实模型调用。
